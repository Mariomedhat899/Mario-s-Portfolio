# Mario's Portfolio

A modern Angular portfolio showcasing projects, experience, education, tech stack, and contact info.

## Sections

- Hero / intro
- About
- Projects
- Tech Stack / skills
- Education
- Contact

## Tech Stack

- Angular
- SCSS
- Standalone components

## Getting Started

```bash
npm install
ng serve
```

Then open `http://localhost:4200/`.

## Build

```bash
ng build
```
